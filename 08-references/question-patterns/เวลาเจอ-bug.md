# คำถามเมื่อ: เจอ Bug / ปัญหา
# สถานการณ์: ระบบทำงานผิดปกติ ต้องหาสาเหตุ

---

## 5 คำถามแรก

1. **ปกติต้องทำงานยังไง?** (expected behavior)
2. **ตอนนี้ทำงานผิดยังไง?** (actual behavior)
3. **เริ่มเกิดตั้งแต่เมื่อไร?** (timeline)
4. **เกิดทุกครั้ง หรือบางช่วง?** (pattern)
5. **มีอะไรเปลี่ยนก่อนหน้านี้?** (recent changes)

---

## คำถามเพิ่มเติม

- มี error message / log ไหม?
- ทำ reproduce (จำลอง) ได้ไหม? ขั้นตอนอะไร?
- กระทบ user กี่คน?
- มี workaround (วิธีแก้ชั่วคราว) ไหม?
- เคยเกิดมาก่อนไหม? แก้ยังไง?
- urgency ระดับไหน? (ต้องแก้ทันทีหรือรอได้?)

---

## สิ่งที่ต้องทำ (ตามลำดับ)

```
1. เก็บ evidence (log, screenshot, steps to reproduce)
2. ตั้ง hypothesis (คิดว่าเป็นเพราะอะไร)
3. ทดสอบ hypothesis ทีละข้อ
4. หา root cause
5. เสนอ fix + tradeoff
6. แก้ + test
7. บันทึก investigation log
```
