# คำถามเมื่อ: รับ Requirement ใหม่
# สถานการณ์: owner/ลูกค้าส่ง req มาให้ ต้องถามให้ชัดก่อนเริ่มทำ

---

## 5 คำถามที่ต้องถาม (ขั้นต่ำ)

1. **เป้าหมายจริงคืออะไร?** — ไม่ใช่แค่สิ่งที่สั่ง แต่สิ่งที่อยากได้จริง
2. **success วัดจากอะไร?** — ตัวเลข/พฤติกรรมที่ต้องเห็น
3. **scope คืออะไร? อะไรที่ไม่ทำ?** — ป้องกัน scope creep
4. **มี deadline ไหม? เพราะอะไร?** — เร่งจริงหรือเร่งเทียม
5. **มีระบบอื่นที่เกี่ยวข้องไหม?** — รู้ upstream/downstream

---

## คำถามเพิ่มเติม (ถ้ามีเวลา)

- ตอนนี้ทำยังไงอยู่? มีปัญหาอะไร?
- ใครใช้? กี่คน?
- มีตัวอย่าง/reference ไหม?
- budget เท่าไร?
- quality ระดับไหน? (prototype vs production)
- ต้อง maintain หลังส่งมอบไหม?
- มี feature ไหนที่ตัดได้ถ้าเวลาไม่พอ?

---

## ตัวอย่าง (Stock)

```
owner: "ทำระบบ stock ให้หน่อย"

คุณ: "ได้ครับ ก่อนเริ่มขอถามเพิ่มนิดนึง:
1. เป้าหมายหลักคืออะไรครับ? (เช่น รู้ stock real-time? ป้องกัน oversell?)
2. สำเร็จแล้วดูจากอะไร? (เช่น stock ตรง 99%?)
3. features ที่ต้องมี phase แรกคืออะไรครับ?
4. ต้องเชื่อมกับระบบอะไรอีกไหม? (POS? บัญชี?)
5. มี deadline ไหมครับ?"
```
