# คำถามเมื่อ: ต้องประเมินเวลา / ราคา
# สถานการณ์: ลูกค้าถามว่า "ใช้เวลาเท่าไร?" หรือ "ราคาเท่าไร?"

---

## 5 คำถามก่อนประเมิน

1. **scope ชัดหรือยัง?** — ถ้าไม่ชัด ประเมินไม่ได้
2. **quality ระดับไหน?** — prototype vs production-grade
3. **มีอะไรที่ซับซ้อน/ไม่เคยทำ?** — เพิ่ม buffer
4. **มี dependency ที่ควบคุมไม่ได้ไหม?** — third-party, owner confirm
5. **เคยทำอะไรคล้ายกันไหม?** — ใช้เป็น reference

---

## วิธีประเมิน

```
1. แบ่ง task ย่อย
2. ประเมินแต่ละ task (ชั่วโมง)
3. รวม
4. คูณ buffer (×1.5 ปกติ, ×2 ซับซ้อน)
5. แปลงเป็นวัน
```

---

## เทคนิค

- **อย่า underestimate** — เผื่อเสมอ
- **บอกเป็น range** — "2-3 สัปดาห์" ไม่ใช่ "2 สัปดาห์"
- **แยก must-have / nice-to-have** — ถ้าไม่พอเวลา ตัด nice-to-have
- **record ไว้** — ทำเสร็จแล้วเทียบกับที่ประเมิน → ปรับครั้งต่อไป
