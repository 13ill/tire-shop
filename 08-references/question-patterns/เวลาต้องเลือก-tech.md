# คำถามเมื่อ: ต้องเลือก Technology / Pattern
# สถานการณ์: ต้องตัดสินใจเลือก framework, database, library, design pattern

---

## 5 คำถามที่ต้องตอบก่อนเลือก

1. **ปัญหาที่ต้องแก้คืออะไร?** — อย่าเลือก tech ก่อนรู้ปัญหา
2. **constraints คืออะไร?** — budget, team size, timeline, existing stack
3. **ต้อง scale ไหม?** — user 5 คน กับ 5000 คน เลือกต่างกัน
4. **ใครดูแลต่อ?** — ถ้าเราดูแลคนเดียว → เลือกอะไรที่ง่าย
5. **ถ้าเลือกผิด ย้อนกลับได้ไหม?** — vendor lock-in risk

---

## คำถามเพิ่มเติม

- มี tech ที่ทีมถนัดอยู่แล้วไหม?
- community + documentation ดีไหม?
- cost ระยะยาวเป็นยังไง?
- ใช้กับ project อื่นในอนาคตได้ไหม?
- มี case study ที่คล้ายกันไหม?

---

## Framework ตัดสินใจ

```
[tradeoff-mode]

ต้องเลือก: [อะไร]
Constraints: [ข้อจำกัด]

ช่วยเสนอ 2-3 ทางเลือก เปรียบเทียบ:
- เวลา setup
- ค่าใช้จ่าย
- ความซับซ้อน
- scalability
- vendor lock-in risk
- community support
```
