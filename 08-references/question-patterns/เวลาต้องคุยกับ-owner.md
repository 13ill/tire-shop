# คำถามเมื่อ: ต้องคุยกับ Owner / ลูกค้า
# สถานการณ์: ต้อง update, ถามเพิ่ม, ต่อรอง, หรือรายงานปัญหา

---

## หลักการคุยกับ Owner

1. **กระชับ** — owner ไม่มีเวลาอ่านยาว
2. **มี structure** — bullet point, ไม่ใช่ paragraph ยาว
3. **ไม่ใช้ศัพท์ tech** — พูดภาษาธุรกิจ
4. **ให้ทางเลือก** — ไม่ถามปลายเปิด
5. **มี action item** — บอกว่า owner ต้องทำอะไร (ถ้ามี)

---

## สถานการณ์ + วิธีเปิด

### ต้องถามเพิ่ม
```
"ก่อนเริ่มทำ ขอถามเพิ่ม 3-5 ข้อ เพื่อให้งานตรงที่สุดนะครับ:"
```

### ต้อง Update Progress
```
"อัปเดตครับ: [สรุป 1-2 บรรทัด]
เสร็จ: [X%]
ถัดไป: [สิ่งที่จะทำ]
ต้องการจากคุณ: [ถ้ามี]"
```

### ต้องแจ้งปัญหา
```
"แจ้งครับ: เจอปัญหา [X]
ผลกระทบ: [อะไร]
กำลังแก้: [ทำอะไรอยู่]
คาดว่าจะเสร็จ: [เมื่อไร]"
```

### ต้องต่อรอง
```
"ได้ครับ ถ้าเพิ่ม feature นี้:
ทาง A: [ทางเลือก + ผลกระทบ]
ทาง B: [ทางเลือก + ผลกระทบ]
ต้องการแบบไหนครับ?"
```

---

## ถ้ากลัวคุย — อ่านตรงนี้

- owner **ชอบคนที่ proactive** (ถามก่อนไม่รอให้เรียก)
- ถามดีกว่าเดาแล้วทำผิด
- "ขอ confirm ก่อน" = professional ไม่ใช่อ่อน
- ใช้ chat/LINE ได้ ไม่ต้อง face-to-face ถ้าไม่สะดวก
