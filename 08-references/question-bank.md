# Question Bank — คลังคำถามรวม
# รวมคำถามทั้งหมดที่ต้องถามในทุกสถานการณ์ — ใช้เป็น quick reference
# แยกตามหมวดหมู่ เลือกใช้ตามสถานการณ์

---

## 1. เป้าหมาย (Goal)
- เป้าหมายจริงคืออะไร? (ไม่ใช่แค่สิ่งที่สั่ง)
- ทำเพื่อแก้ปัญหาอะไร?
- success วัดจากอะไร? (ตัวเลข/พฤติกรรม)
- ถ้าไม่ทำจะเกิดอะไร?
- ใครได้ประโยชน์? ใครเสียประโยชน์?
- temporary fix หรือ permanent solution?

## 2. ขอบเขต (Scope)
- scope ครอบคลุมอะไร?
- อะไรที่ **ไม่อยู่** ใน scope?
- phase แรก (MVP) ต้องมีอะไร?
- มีงานที่ต้องทำก่อนไหม? (prerequisite)
- deadline คือเมื่อไร? เพราะอะไร?
- ถ้า budget/เวลาไม่พอ ตัดอะไรได้?

## 3. ระบบ (System)
- ระบบนี้เกี่ยวกับ module ไหน?
- upstream (ส่งข้อมูลเข้ามา) คืออะไร?
- downstream (รับข้อมูลจากเรา) คืออะไร?
- dependency (พึ่งพาอะไร) มีอะไรบ้าง?
- มี shared service (service ที่ใช้ร่วมกัน) ไหม?
- data flow (ข้อมูลไหลยังไง) เป็นอย่างไร?

## 4. ความเสี่ยง (Risk)
- ถ้าแก้ผิด impact (ผลกระทบ) คืออะไร?
- มี rollback (ย้อนกลับ) ได้ไหม?
- data corruption (ข้อมูลเสียหาย) เป็นไปได้ไหม?
- performance (ความเร็ว) จะกระทบไหม?
- security (ความปลอดภัย) มี risk ไหม?
- ถ้าพังจะกระทบกี่คน? เสียเงินเท่าไร?

## 5. ปฏิบัติการ (Operations)
- monitor (เฝ้าดู) อะไรหลัง deploy?
- ต้องแจ้งใครบ้าง?
- peak hour (ชั่วโมงเร่งด่วน) คือเมื่อไร?
- ต้อง feature flag (สวิตช์เปิด/ปิด) ไหม?
- ต้อง prepare hotfix (เตรียมแก้ด่วน) ไหม?

## 6. ปัญหา (Problem Diagnosis)
- ปัญหานี้เริ่มตั้งแต่เมื่อไร?
- เกิดทุกครั้งหรือบางช่วง?
- มีตัวอย่าง case ไหม?
- expected behavior (ควรเป็นยังไง)?
- current behavior (ตอนนี้เป็นยังไง)?
- มี deadline เพราะอะไร?
- business impact (ผลกระทบต่อธุรกิจ)?
- เคยเกิดมาก่อนไหม?
- มีอะไรเปลี่ยนก่อนหน้านี้?

## 7. เทคโนโลยี (Technology)
- tech stack ต้องเป็นอะไร? หรือเลือกได้?
- มี legacy (ระบบเดิม) ที่ต้องเชื่อมไหม?
- performance requirement เป็นยังไง?
- user กี่คน? concurrent กี่คน?
- ต้อง scale ในอนาคตไหม?

## 8. ธุรกิจ (Business)
- budget (งบ) มีเท่าไร?
- ROI (ผลตอบแทน) คุ้มไหม?
- มี competitor (คู่แข่ง) ที่ทำอยู่แล้วไหม?
- ถ้าทำช้า 1 เดือน เสียหายอะไร?
- ลูกค้ายินดีจ่ายเท่าไร?
