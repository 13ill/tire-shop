# Negotiation Guide — วิธีต่อรอง/ปฏิเสธอย่างมืออาชีพ
# ใช้เมื่อ: ต้องต่อรอง scope/ราคา/deadline กับ owner หรือลูกค้า
# หลัก: ต่อรองไม่ใช่ทะเลาะ — แต่คือหา win-win ให้ทั้งสองฝ่าย

---

## ทำไมต้องต่อรอง?

```
ถ้าไม่ต่อรอง:
- scope บาน → ทำงานฟรี
- deadline เร่งเกินไป → งาน quality ต่ำ
- ราคาถูกเกินไป → ไม่คุ้ม
- รับทุกอย่าง → burn out

ถ้าต่อรองเป็น:
- งานพอดี scope → ส่งทัน quality ดี
- ราคาเหมาะสม → ทั้งสองฝ่าย happy
- relationship ดีขึ้น → owner เคารพความเห็นเรา
```

---

## สถานการณ์ + วิธีพูด

### 1. Owner ขอเพิ่ม scope (scope creep)

❌ ไม่ควร: "ได้ครับ ทำเพิ่มให้" (แล้วเจ็บตัว)
❌ ไม่ควร: "ทำไม่ได้" (ดูไม่ professional)

✅ ควรพูด:
```
"ได้ครับ feature นี้ทำได้ ขอประเมินก่อนนะครับ

ถ้าเพิ่ม feature นี้:
- เวลาเพิ่ม: +3 วัน
- ค่าใช้จ่ายเพิ่ม: +X บาท
- หรือถ้าต้องอยู่ใน timeline เดิม → ต้องตัด feature [Y] ออก

ต้องการแบบไหนครับ?"
```

### 2. Deadline เร่งเกินไป

✅ ควรพูด:
```
"ผมอยากส่งงาน quality ดีที่สุดให้ครับ

ถ้า deadline [วันที่]:
- ทางเลือก A: ทำ MVP (features หลัก 3 อย่าง) → ส่งทัน
- ทางเลือก B: ทำครบทุก feature → ต้องขยาย +1 สัปดาห์

แนะนำทาง A ครับ เพราะได้ใช้งานเร็ว แล้วค่อยเพิ่ม feature ทีหลัง
ต้องการแบบไหนครับ?"
```

### 3. ราคาไม่เหมาะสม (ลูกค้าต่อราคา)

✅ ควรพูด:
```
"ผมเข้าใจเรื่อง budget ครับ

ถ้า budget [X] บาท ผมปรับ scope ให้ลงตัว:
- ตัด feature [A] ออก (ทำทีหลังได้)
- ลด quality จาก production-grade เป็น prototype
- หรือแบ่งเป็น phase: phase 1 = [X] บาท, phase 2 = [Y] บาท

ทางไหนเหมาะกับ business ครับ?"
```

### 4. ต้องปฏิเสธงาน

✅ ควรพูด:
```
"ขอบคุณที่นึกถึงครับ ตอนนี้ติดงานอยู่ไม่สามารถรับได้ช่วง [เวลา]

ทางเลือก:
- เริ่มหลัง [วันที่] ได้ไหมครับ?
- หรือถ้าด่วนมาก ผมแนะนำ [คนอื่น/บริษัทอื่น] ครับ"
```

### 5. Owner เปลี่ยนใจบ่อย

✅ ควรพูด:
```
"ได้ครับ ขอ confirm สิ่งที่เปลี่ยนนะครับ:

เดิม: [สิ่งที่ตกลงไว้]
ใหม่: [สิ่งที่เปลี่ยน]
ผลกระทบ: [เวลาเพิ่ม/ค่าใช้จ่ายเพิ่ม/feature ที่ต้องตัด]

confirm ว่าเข้าใจตรงกันก่อน แล้วผมปรับแผนให้ครับ"
```

---

## หลักการต่อรอง

1. **ให้ทางเลือก ไม่ใช่ปฏิเสธตรงๆ** — "ทำได้ครับ แต่ต้อง..." ดีกว่า "ไม่ได้"
2. **อ้างอิงข้อเท็จจริง** — ใช้ตัวเลข (เวลา, เงิน) ไม่ใช่ความรู้สึก
3. **คิดแบบ win-win** — ทั้งเราและ owner ต้อง OK
4. **เขียนทุกอย่าง** — สิ่งที่ตกลงต้องเขียนไว้ (LINE/email) ไม่ใช่คุยปากเปล่า
5. **ใจเย็น** — ไม่ต้องตอบทันที "ขอประเมินก่อน" ได้เสมอ

## ประโยคมีประโยชน์

| สถานการณ์ | ประโยค |
|---|---|
| ต้องเวลาคิด | "ขอประเมินแล้วตอบกลับภายใน [เวลา] นะครับ" |
| scope ไม่ชัด | "ขอ confirm scope ก่อนเริ่มนะครับ เพื่อให้ได้งานตรงที่สุด" |
| เร่งเกินไป | "อยากส่งงานดีที่สุดให้ครับ ถ้าเร่งมาก quality อาจลดลง" |
| งานเพิ่ม | "ได้ครับ เป็น change request นะครับ ขอประเมินผลกระทบก่อน" |
| ราคาต่ำ | "ผมปรับ scope ให้เข้ากับ budget ได้ครับ" |
