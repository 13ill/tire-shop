# Maturity Levels — ระดับความเชี่ยวชาญ
# ใช้เพื่อ: ประเมินตัวเองว่าอยู่ตรงไหน + รู้ว่าต้องพัฒนาอะไร

---

## 5 Levels

### Level 1: Beginner — "ใช้ AI generate code"
```
พฤติกรรม:
- ถาม AI สั้นๆ "ทำ X ให้หน่อย"
- ไม่ให้ context
- copy-paste โดยไม่เข้าใจ
- ไม่รู้ว่า code ทำงานยังไง

ผลลัพธ์:
- งานออกช้า (เพราะต้องแก้ bug เยอะ)
- quality ต่ำ
- ไม่มีทิศทาง
```

### Level 2: Developing — "เริ่มคิดเชิงระบบ" ← คุณอยู่ตรงนี้
```
พฤติกรรม:
- เริ่มให้ context กับ AI มากขึ้น
- เริ่มคิดก่อนทำ (บ้าง)
- ยังข้ามขั้นตอนบ่อย
- ยังประเมินเวลา/scope ไม่แม่น
- ยังกลัวถาม owner

ผลลัพธ์:
- งานดีขึ้นแต่ยังต้อง rework
- เร็วขึ้นแต่ยังไม่ consistent
```

### Level 3: Intermediate — "ถามเป็น คิดเป็น"
```
พฤติกรรม:
- ผ่าน Gate System ได้คล่อง
- ถาม owner ได้อย่างมั่นใจ
- ใช้ AI ด้วย structured prompt ทุกครั้ง
- ประเมินเวลาแม่น ±30%
- มี decision log สม่ำเสมอ
- เข้าใจ system thinking

ผลลัพธ์:
- ไม่ต้อง rework บ่อย
- quality สม่ำเสมอ
- owner ไว้ใจมากขึ้น
```

### Level 4: Advanced — "AI Copilot"
```
พฤติกรรม:
- ใช้ AI เป็น operational partner
- สั่ง AI ทำงาน complex ได้
- ต่อรอง scope/ราคาได้
- ออกแบบ architecture ได้
- ประเมินแม่น ±20%
- คิดแบบ business owner

ผลลัพธ์:
- ทำงานเร็ว 2-3x
- quality สูง consistent
- เริ่มสร้าง product ได้
```

### Level 5: High-Level Operator — "สั่งจากมุมบน"
```
พฤติกรรม:
- เป็น "คนสั่ง" ไม่ใช่ "คนทำ"
- สร้าง system + workflow ที่ทำซ้ำได้
- มี product ที่สร้างรายได้
- สั่ง AI ทำ 80% ของงาน
- focus ที่ strategy + decision
- ต่อรอง + สื่อสารเก่ง

ผลลัพธ์:
- ทำงานน้อย ได้ผลเยอะ
- มีรายได้จาก product
- เป็น business owner จริง
```

---

## วิธีประเมินตัวเอง

ทุก 2 สัปดาห์ ลองตอบ:

| คำถาม | Level 2 | Level 3 | Level 4 | Level 5 |
|---|---|---|---|---|
| ถาม owner ได้มั่นใจไหม? | กลัว | เริ่มกล้า | มั่นใจ | เป็นธรรมชาติ |
| ใช้ Gate System ไหม? | บางครั้ง | ทุกครั้ง | อัตโนมัติ | สอนคนอื่นได้ |
| ประเมินเวลาแม่นไหม? | ผิดเยอะ | ±30% | ±20% | ±10% |
| ต่อรอง scope ได้ไหม? | ไม่กล้า | พยายาม | ทำได้ | เก่ง |
| สั่ง AI ได้ดีไหม? | สั้นๆ | มี context | structured | strategic |
| มี product ไหม? | ไม่มี | มีไอเดีย | กำลังทำ | มีรายได้ |

---

## วิธีขึ้น Level

| จาก → ไป | ต้องทำอะไร |
|---|---|
| 2 → 3 | ใช้ Gate System ทุก task + ฝึกถาม owner + structured prompt |
| 3 → 4 | ฝึก delegation + estimation + negotiation + architect |
| 4 → 5 | สร้าง product + สร้าง system ที่ทำซ้ำได้ + ลดงาน manual |
