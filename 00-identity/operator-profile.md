## Maturity Level ปัจจุบัน

```
[■■□□□] Level 2/5 — Developer ที่เริ่มคิดเชิงระบบ

Level 1: Beginner        — ใช้ AI generate code
Level 2: Developing      — ← คุณอยู่ตรงนี้ (พฤษภาคม 2026)
Level 3: Intermediate    — ใช้ AI วิเคราะห์ + ออกแบบ ถามเป็น
Level 4: Advanced        — ใช้ AI เป็น operational copilot คิดเชิงระบบได้
Level 5: High-Level Op   — สร้าง AI workflow ecosystem ทำงานน้อย สั่งจากมุมบน
```

- มี req จริง — มีสนามฝึกจริง

## จุดอ่อนที่ต้องพัฒนา

### Technical
| จุดอ่อน | ผลกระทบ | ระบบช่วยยังไง |
|---|---|---|
| เลือก technology/pattern ไม่มั่นใจ | ใช้เวลาตัดสินใจนาน หรือเลือกผิด | tradeoff-mode |
| DevOps / Deploy / Infra ไม่ชำนาญ | deploy ไม่มั่นใจ ไม่มี monitoring | deployment-safety checklist |

### Business / Soft Skill
| จุดอ่อน | ผลกระทบ | ระบบช่วยยังไง |
|---|---|---|
| กลัวถาม owner/ลูกค้า | ได้ข้อมูลไม่ครบ → ทำผิด | question-bank + coaching-mode |
| ประเมินเวลา/ราคา/scope ไม่ได้ | รับงานแล้วเจ็บตัว | estimation-mode |
| สื่อสาร/นำเสนอยาก | owner ไม่เข้าใจสิ่งที่คิด | communication template |
| ปฏิเสธ/ต่อรองไม่ได้ | scope บาน + งานเยอะเงินน้อย | negotiation-guide |

## พฤติกรรมที่ต้องเปลี่ยน

| พฤติกรรมเดิม | พฤติกรรมใหม่ที่ต้องฝึก |
|---|---|
| คิดในหัวคร่าวๆ แล้วลงมือ | ผ่าน Gate ก่อน → เขียนออกมา → จึงลงมือ |
| ถาม AI แบบสั้นๆ | ให้ context + ใช้ prompt structure |
| ทำไปครึ่งทางแล้วย้อนกลับ | Pre-code gate → คิดให้จบก่อน code |
| scope บานออก | Deep intake → scope ชัดตั้งแต่ต้น |
| ตัดสินใจไม่ได้ | Tradeoff mode → AI ช่วยวิเคราะห์ |
| context หาย | Versioned log → บันทึกทุกครั้ง |
