# Growth Roadmap 9 เดือน
# แผนพัฒนาตัวเองจาก Developer → Business Owner / Solution Architect
# เริ่ม: พฤษภาคม 2026

---

## Phase 1: Foundation (เดือน 1-3) — "คิดเป็น ถามเป็น"

### เป้าหมาย
- คิดเป็นระบบได้ก่อนลงมือทำ
- ถามคำถามสำคัญได้โดยไม่กลัว
- ใช้ AI เป็น thinking partner ไม่ใช่แค่ code generator

### สิ่งที่ต้องทำ

| สัปดาห์ | กิจกรรม | วัดผลจาก |
|---|---|---|
| 1-2 | ใช้ Gate System กับทุก task — ผ่าน Gate 1 ทุกครั้ง | ทุก task มี intake checklist ที่กรอกแล้ว |
| 3-4 | ฝึกถามกลับ owner — ใช้ question-bank | ถาม owner ได้อย่างน้อย 3 คำถามต่อ task |
| 5-6 | ฝึกใช้ AI ด้วย prompt structure (Context/Goal/Constraints/Need) | prompt ยาวขึ้น มี context ชัดขึ้น |
| 7-8 | ฝึก tradeoff thinking — ทุกการตัดสินใจต้องมี 2+ ทางเลือก | มี decision log อย่างน้อย 5 entries |
| 9-10 | ฝึก system thinking — วาด upstream/downstream ทุก task | system map ทุก task |
| 11-12 | ทบทวน: อ่าน decision logs + lessons ที่ผ่านมา | สรุป lessons top 5 |

### KPI ที่ต้องถึง ณ สิ้นเดือน 3
- [ ] ผ่าน Gate 1-2 ทุก task โดยไม่ต้องถูกเตือน
- [ ] ถาม owner ได้คล่อง ไม่กลัว
- [ ] ใช้ AI ด้วย structured prompt ทุกครั้ง
- [ ] มี decision log อย่างน้อย 10 entries
- [ ] ประเมินเวลางานง่ายๆ ได้แม่น ±30%

## Phase 2: Acceleration (เดือน 4-6) — "เร็วขึ้น มั่นใจขึ้น"

### เป้าหมาย
- ทำงานเร็วขึ้น 2x (เพราะไม่ต้องย้อนกลับ)
- ประเมินงาน + ราคาได้
- ต่อรอง scope/deadline ได้
- เริ่มวาง product ตัวเอง

### สิ่งที่ต้องทำ

| สัปดาห์ | กิจกรรม | วัดผลจาก |
|---|---|---|
| 13-14 | ฝึก estimation — ทุก task ประเมินเวลาก่อนทำ แล้วเทียบจริง | estimation accuracy ±20% |
| 15-16 | ฝึกต่อรอง — ใช้ negotiation-guide ต่อรอง scope กับ owner | ต่อรองสำเร็จ 1+ ครั้ง |
| 17-18 | เริ่มคิด product — ใช้ product-thinking checklist คิด product 1 ตัว | มี product brief 1 ชิ้น |
| 19-20 | ฝึก delegation — สั่ง AI ทำงาน complex โดยไม่ต้องลงมือเอง | AI ทำ task สำเร็จ 3+ tasks |
| 21-22 | ฝึก architect — design system ก่อน code ทุกครั้ง | architecture doc ทุก project |
| 23-24 | ทบทวน: เทียบกับ Phase 1 — เร็วขึ้นจริงไหม? | เวลาต่อ task ลดลง 50% |

### KPI ที่ต้องถึง ณ สิ้นเดือน 6
- [ ] ประเมินเวลาแม่น ±20%
- [ ] ต่อรองได้ ปฏิเสธได้
- [ ] มี product idea + brief 1 ตัว
- [ ] สั่ง AI ทำงาน complex ได้
- [ ] ไม่ต้องย้อนกลับมาแก้ (ลดจาก 80% → 20%)

## Phase 3: Mastery (เดือน 7-9) — "สร้าง product สั่งจากมุมบน"

### เป้าหมาย
- สร้าง product ขายได้จริง
- ทำงานน้อยลง — เป็นคนสั่ง ไม่ใช่คนทำ
- มี system ที่ทำซ้ำได้ (repeatable)

### สิ่งที่ต้องทำ

| สัปดาห์ | กิจกรรม | วัดผลจาก |
|---|---|---|
| 25-28 | สร้าง product MVP — ใช้ AI ทำ 80% ของ code | product MVP ใช้งานได้จริง |
| 29-32 | ทดสอบ + ปรับปรุง — ให้คนใช้จริง + เก็บ feedback | มี user จริง 5+ คน |
| 33-36 | ขาย/launch — ตั้งราคา + หาลูกค้า | มีรายได้จาก product |

### KPI ที่ต้องถึง ณ สิ้นเดือน 9
- [ ] มี product ที่ใช้งานได้จริง 1 ตัว
- [ ] มีรายได้ (แม้จะน้อย) จาก product
- [ ] ทำงาน "ลงมือเอง" ลดลง 60%
- [ ] สั่ง AI + system ทำงานส่วนใหญ่ได้
- [ ] มี repeatable workflow ที่ใช้กับ project ถัดไปได้

## วิธีติดตาม Progress

ทุก 2 สัปดาห์:
1. เปิดไฟล์นี้
2. เช็ค KPI ของ phase ปัจจุบัน
3. ถาม AI: "ช่วยทบทวน progress ของฉัน"
4. อัปเดต `operator-profile.md` → maturity level

## หมายเหตุ

- ไม่ต้องสมบูรณ์แบบ — 80% ดีพอ แล้วปรับทีหลัง
- ถ้าช้ากว่าแผน → ปรับแผน ไม่ใช่ท้อ
- เป้าหมายคือ "พัฒนาทุกวัน" ไม่ใช่ "สมบูรณ์วันแรก"
- AI จะช่วยเตือน + coaching ตลอดทาง
