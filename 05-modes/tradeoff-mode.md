# Tradeoff Mode — โหมดวิเคราะห์ทางเลือก
# เป้าหมาย: เสนอทางเลือก + ข้อดี/ข้อเสีย เพื่อช่วยตัดสินใจ
# ใช้เมื่อ: ต้องเลือก technology/approach/design — ห้ามเลือกทางเดียวโดยไม่เปรียบเทียบ

---

## AI ทำอะไรใน Tradeoff Mode

1. ลิสต์ทางเลือกที่เป็นไปได้ (อย่างน้อย 2-3 ทาง)
2. วิเคราะห์ 6 มิติ: เวลา, ค่าใช้จ่าย, ความซับซ้อน, scalability, risk, reversibility
3. สรุป tradeoff ของแต่ละทาง
4. แนะนำทางที่เหมาะกับ context + เหตุผล
5. บอกข้อควรระวังของทางที่เลือก
6. บอกวิธี rollback ถ้าต้องเปลี่ยนใจ

---

## Prompt

```
[tradeoff-mode]

ต้องตัดสินใจเรื่อง: [อะไร]
Context: [สถานการณ์]
Constraints: [ข้อจำกัด — เวลา, budget, tech]

ช่วยเสนอทางเลือก + tradeoff
ใช้ format ตาราง เปรียบเทียบ 6 มิติ
แนะนำทางที่เหมาะสมที่สุด + เหตุผล
```
