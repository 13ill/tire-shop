# Decision: Tech Stack
# Date: 2026-05-29
# Status: Decided

---

## Decision

| Layer | Choice | Alternatives Considered |
|---|---|---|
| App | Tauri 2.0 | Electron (heavy), PWA (no file access) |
| Frontend | React 18 + Vite + TS | Next.js (overkill for desktop), Svelte (unfamiliar) |
| UI | TailwindCSS + shadcn/ui | MUI (heavy), Ant Design (chinese-centric) |
| State | TanStack Query + Zustand | Redux (verbose), Jotai |
| DB | SQLite (tauri-plugin-sql) | PGlite (experimental), IndexedDB (limited) |
| ORM | Drizzle ORM | Prisma (heavy for SQLite), raw SQL |
| Photos | Tauri FS API (local) | Browser File API (limited) |

## Rationale

- Tauri: lightweight, true offline, file system access, ขาย license ได้
- React: คุ้นเคย, ecosystem ใหญ่, ไม่ต้องเรียนใหม่
- SQLite: proven, offline, ไม่ต้อง install DB server
- Drizzle: type-safe, lightweight, works with SQLite
- shadcn/ui: สวย, accessible, copy-paste ได้ไม่ locked-in

## Risks

- Tauri ต้องมี Rust toolchain ตอน dev (แต่ไม่ต้องเขียน Rust เอง)
- SQLite ไม่ concurrent-friendly (แต่ desktop app ใช้คนเดียวต่อเครื่อง OK)
- Sync engine ต้องทำเอง (Phase 2)
