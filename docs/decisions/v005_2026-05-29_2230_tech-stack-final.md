## Hosting Strategy

| Phase | Hosting | เหตุผล |
|---|---|---|
| Phase 1 (ร้านแรก) | Shared hosting (cPanel + Node.js) | ถูก ไม่ต้องดูแล โฟกัส feature |
| Phase 2 (productize) | VPS + Docker | scale หลายร้าน |

## Rationale

- All "A" choices = lightweight, modern, performant, consistent
- MySQL/MariaDB = shared hosting มีให้ ไม่ต้อง setup
- Drizzle = type-safe + lightweight + MySQL support + ไม่มีปัญหา binary engine แบบ Prisma
- Hono = เร็ว + เบา + TypeScript first-class + API คล้าย Express
- shadcn/ui + TanStack Table = POS-ready (table heavy) + modern + customizable
- Dexie.js = IndexedDB wrapper ที่ดีที่สุด สำหรับ offline sync
- vite-plugin-pwa = PWA + service worker + installable
