# Goal Clarification — ถามเป้าหมายให้ชัด
# ใช้เมื่อ: ได้รับ task/requirement ใหม่ — ต้องหา "business intent" (สิ่งที่ธุรกิจต้องการจริงๆ)

---

## ทำไมต้องทำขั้นตอนนี้?

เพราะสิ่งที่ owner พูด กับ สิ่งที่ต้องการจริง มักไม่ตรงกัน:

| owner พูด | สิ่งที่ต้องการจริง |
|---|---|
| "ทำระบบ stock" | รู้ว่าสินค้าเหลือเท่าไร real-time |
| "แก้ API ช้า" | ลูกค้าไม่ timeout ตอน peak hour |
| "ทำ POS" | พนักงานขายของได้เร็วขึ้น ลดคิวยาว |
| "ทำ report" | ผู้บริหารตัดสินใจสั่งของได้ถูกเวลา |

---

## Checklist คำถาม

### A. เป้าหมายที่แท้จริง (Business Intent)

| # | คำถาม | หมายความว่า | ตัวอย่าง Stock/POS | คำตอบ |
|---|---|---|---|---|
| 1 | เป้าหมายจริงคืออะไร? | ไม่ใช่สิ่งที่สั่ง แต่สิ่งที่อยากได้จริง | "รู้ stock real-time" ไม่ใช่แค่ "ทำระบบ stock" | |
| 2 | ทำเพื่อแก้ปัญหาอะไร? | ตอนนี้เจ็บปวดตรงไหน | "ขายของเกิน stock เพราะไม่รู้ว่าหมด" | |
| 3 | ถ้าไม่ทำจะเกิดอะไร? | วัด urgency | "ลูกค้าจ่ายแล้วแต่ไม่มีของส่ง → refund + เสียชื่อ" | |
| 4 | success วัดจากอะไร? | ตัวเลขที่ต้องเห็น | "stock ตรง 99% ทุกสิ้นวัน" | |
| 5 | ใครได้ประโยชน์? | stakeholder (ผู้มีส่วนได้ส่วนเสีย) | "ทีม warehouse + ทีมขาย + ลูกค้า" | |

### B. ระดับความเร่งด่วน (Urgency)

| # | คำถาม | หมายความว่า | ตัวอย่าง | คำตอบ |
|---|---|---|---|---|
| 1 | deadline คือเมื่อไร? | วันที่ต้องเสร็จ | "สิ้นเดือนนี้" | |
| 2 | ทำไมต้องเสร็จวันนั้น? | เร่งจริงหรือเร่งเทียม | "เพราะ investor จะมาดู" vs "แค่อยากได้เร็ว" | |
| 3 | urgency ระดับไหน? | critical/high/medium/low | "ลูกค้าโวยทุกวัน = critical" | |
| 4 | temporary fix หรือ permanent? | กลยุทธ์ต่างกัน — ชั่วคราว vs ถาวร | "แก้ไขด่วนก่อน แล้วทำใหม่ทีหลัง" | |

### C. owner กังวลอะไร? (Risk Awareness)

| # | คำถาม | หมายความว่า | ตัวอย่าง | คำตอบ |
|---|---|---|---|---|
| 1 | owner กังวลอะไรมากที่สุด? | priority ที่แท้จริง | "กลัว stock ติดลบ" | |
| 2 | เคยเกิดปัญหาอะไรมาก่อน? | ดู pattern ซ้ำ | "เคย oversell 3 ครั้งเดือนที่แล้ว" | |
| 3 | มีอะไรที่ห้ามพังเด็ดขาด? | ขีดเส้นแดง | "ห้ามกระทบยอดขาย" | |

---

## วิธีใช้

1. อ่านคำถามทุกข้อ
2. ข้อไหนตอบได้ → กรอกเลย
3. ข้อไหนตอบไม่ได้ → **ถาม owner ทันที** (ใช้คำถามตามตารางได้เลย)
4. ถ้ากลัวถาม → คิดว่า "ถ้าไม่ถามตอนนี้ แล้วทำผิด จะเสียเวลามากกว่า"
